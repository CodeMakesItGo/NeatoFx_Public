Overview
The NeatoFX Target IR is a WiFi-enabled, all-in-one IR target controller built for professional shooting galleries, laser tag arenas, and themed attractions. Each unit combines IR hit detection, addressable RGB lighting, relay-controlled props, servo actuation, real-time scoring, and full Home Assistant integration. Targets operate fully standalone with no additional controller hardware — a central server is only needed when networked scoring is required. Deploy a single target or a scalable gallery, all individually addressable and OTA-updatable.
◎
IR Detection & Hit Logic
  • IR receiver (38kHz HS0038B) — high sensitivity, ambient-light tolerant
  • Custom IR protocol capable — define your own signal for full system control
  • IR auto-disables on hit — prevents double-counting
  • Adjustable point values — set per-target scoring directly from the web UI
  • Shooter ID / team color passed to Home Assistant on every hit
✦
RGB Lighting
  • 6 × WS2812 addressable LEDs on target face — full RGB
  • Secondary LED strip output — up to 100 LEDs (Rev 3.x)
  • 5 idle effects: Solid, Rainbow, Color Wipe, Scanner, Twinkle
  • 9 solid color presets selectable from web UI
  • Separate hit effect selectable per target
  • Custom RGB patterns capable — define unique sequences per target
  • LED state persists across reboots — picks up exactly where it left off
  • Power failure detection — flashes red on aux power fault
⚡
Prop & Power Outputs
  • Relay output — 2A @ 24VDC / 2A @ 120VAC, configurable hold time
  • Servo output — standard PWM, -85° to +85° slider, 5V @ 3A aux
  • Ground switch — 20V @ 1.6A FET output for external components
  • 2 × 5V aux power outputs — 3A each for external devices
  • Auxiliary power control — enable/disable servo/relay to conserve energy
  • All outputs boot-safe (off on power-up)
  • PWM output — drives visual effects like light flicker or prop throttle control
◈
Scoring & Game Integration
  • Configurable point value per target — adjustable from web UI (default: 10 pts)
  • Hit events broadcast with: target ID, shooter/team ID, point value
  • Player/team identification — IR command code identifies each shooter
  • Laser tag team detection — Red, Green, Blue, White scoring
  • Supports friendly-fire detection and team-specific effects
  • Scalable multi-target deployments — each unit individually addressable
  • Game modes: Timed Challenge, Shot Count, Team Coverage, Last Target Standing, Sequence, and more
  • Pairs with NeatoFX devices such as SmartSpeaker, motor controller, and other NeatoFX accessories
⬡
Networking & Control
  • WiFi client mode — static IP, Home Assistant API
  • Standalone AP mode — no router required, works out of box
  • Built-in browser-based control panel — no app needed
  • Captive portal for easy first-time setup
  • OTA firmware updates — update all targets remotely
  • WiFi signal strength monitoring and weak-signal alerts
  • RS232 TX/RX headers for serial device integration
#
Inputs & Sensing
  • 3 × GPIO — debounced, connect any switch or sensor to ground
  • Analog voltage input — 0–3.3V ADC for pressure sensors, potentiometers
  • Remotely triggerable via API or Web UI — fire hit sequences from any automation
  • Device uptime sensor
  • Analog voltage sensor with low-voltage alert
  • All inputs report state to Home Assistant in real time

Easy Mounting

Standard ¼" camera mount on base with included CCTV swivel mount — installs on walls, ceilings, posts, or upside down in any direction. No custom brackets needed.

Ideal Applications
Shooting Galleries

IR targets score hits, flash RGB effects, and report scores to a central game controller in real time. Pairs with SmartSpeaker for audio.

Laser Tag Arenas

Team-aware targets track Red, Green, Blue, and White team hits — enabling team scoring, friendly-fire detection, and team-specific effects.

Haunted House Props

A hit triggers relay (solenoid/air cannon), LED flash, servo reveal, and FPP light sequence simultaneously from one unit.

Escape Rooms

Laser targets as puzzle elements — hitting the right sequence triggers events via Home Assistant automations.

Carnival & Midway Games

Each target fires its own hit effect independently while reporting to a central scoreboard display.

Animatronic Activation

External trigger input lets any sensor (PIR, pressure pad, button) fire the full hit sequence — no IR gun required.
